# hello-github-page

This repository is a beginner-friendly starter site to learn GitHub and GitHub Pages.

## What I updated
- Improved the site layout with a navbar, hero section, features grid and instructions.
- Added links in the site to the repository, Issues, Pull Requests, Actions, Releases, Wiki and Settings.
- Updated CSS and JS for responsive behavior and small interactivity.

## How to access GitHub features for this repo
- Repository: https://github.com/Amitsharma090/hello-github-page
- Pages (live demo): https://Amitsharma090.github.io/hello-github-page (enable in Settings → Pages)
- Issues: https://github.com/Amitsharma090/hello-github-page/issues — create issues to report bugs or request features.
- Pull Requests: https://github.com/Amitsharma090/hello-github-page/pulls — propose changes by creating a branch and opening a PR.
- Actions: https://github.com/Amitsharma090/hello-github-page/actions — add workflows under `.github/workflows/` to automate tests or deployments.
- Releases: https://github.com/Amitsharma090/hello-github-page/releases — publish downloadable snapshots.
- Wiki: https://github.com/Amitsharma090/hello-github-page/wiki — optional project documentation.
- Settings: https://github.com/Amitsharma090/hello-github-page/settings — manage pages, collaborators, branches, secrets.
