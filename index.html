How to edit this page

  1. Open the repository on GitHub and click a file (for example index.html).
  2. Click the pencil icon to edit the file directly in the browser, then propose the change.
  3. Create a branch and a Pull Request, review, and merge to apply the change.

Try editing the index.html file now on GitHub.

Next steps

You can:

  • Enable GitHub Pages in the repository Settings → Pages → choose branch 'main' and root folder.
  • Create an Issue to ask for a feature.
  • Make a small change in index.html on GitHub and open a Pull Request.
  • Add a GitHub Action under .github/workflows to run tests automatically.
